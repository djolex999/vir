# `vir dream` M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `vir dream [project]` rebuilds `projects/<slug>.md` as a size-capped reference page. Every entry on it carries a code-verified verbatim quote from a source note, plus a confirmed/unconfirmed label derived from check data.

**Architecture:**
- A new `src/dream/` module runs a pure pipeline: select → prompt → parse → validate → render. `run.ts` wires it together with an injected `llm`, the same pattern as `src/audit/ground.ts`.
- The CLI (`src/cli/dream.ts`) follows `src/cli/audit.ts`: estimate the cost, offer a dry run, confirm, then run under the pipeline lock.
- `vir summarize <project>|--all` delegates to dream.
- The existing auto-summary step in the distill pass must not overwrite a dream page.

**Tech Stack:** TypeScript strict, vitest, better-sqlite3 (existing `StateDb`), commander. No new packages.

**Spec:** `docs/superpowers/specs/2026-11-16-vir-dream-design.md`, approved 2026-11-16 with: replace summarize (keep it as an alias), show unconfirmed entries, use `models.distill`, no daemon auto-dream in M1.

**Base:** branch `claude/vir-dream`, cut from `claude/check-most-used-first` (`aacfa83`). It needs `noteRef` from `src/pipeline/slug.ts`, which exists only on that branch.

## Global Constraints

- **Writes:** dream writes only `<vault>/<outputDir>/projects/<slug>.md`. It never edits, moves or deletes a note.
- **Input:** dream never reads its previous page, topic pages, summaries or transcripts.
- **Input budget:** 60,000 tokens, estimated as chars / 4. Notes past the budget enter as topic + lesson, or topic + the first 300 chars of content.
- **Caps:** at most 40 entries and 12 KB per page body (frontmatter and changelog excluded). Page/source ratio ≤ 0.35.
- **Quotes:** each quote is ≤ 200 chars and must be a whitespace-normalised substring of its source note's content.
- **Excluded notes:** `flaggedNotePaths(db.listAudits(), db.listGrounds())` are left out unless `noteIsVerified(root, row)`.
- **Labels:** confirmed = status `verified` or `transcript-supported`; unconfirmed = `unchecked` or `unbacked`.
- **Threshold:** `--min-notes` defaults to 5.
- **LLM:** maxTokens 8000; cost stage `"dream"`; model `cfg.models.distill`, unless `--model haiku|sonnet`.
- **Frontmatter keys, in order:** `project`, `generated`, `sessions`, `kind: dream`, `input_hash`, `notes`, `entries`, `confirmed`, `ratio`, `model`.
- **Changelog:** the `## Changelog` section survives a rewrite. Each new line reads `- YYYY-MM-DD: dream, N notes, E entries (C confirmed)`.

## Review Focus

1. **A project with a single quote** (`it's`) **or a markdown-heavy note:** the quote check must compare whitespace-normalised text only and keep the original characters. Owned by Task 3.
2. **An empty or near-empty model reply** (`{"sections":[]}`, or prose with no JSON): parse throws `DreamParseError`, the run reports it and writes nothing. Owned by Tasks 2 and 5.
3. **A project name with spaces or capitals** (`Pripremi.rs`, `TRAIN`): rows match by `kebab(r.project) === kebab(arg)`, and the page path uses the kebab slug, the same as `summarizeProject`. Owned by Task 1.
4. **The distill pass after a dream:** a page with `kind: dream` is not overwritten by the auto-summary step in `src/pipeline/run.ts`. Owned by Task 7.
5. **A model citing the same note for every entry, or an index of 0 or N+1:** out-of-range sources are dropped, and coverage reflects it. Owned by Task 3.

**Interfaces:**

  ```ts
  export interface DreamNote { index: number; row: DistilledRow; ref: string; status: NoteStatus; surfaced: number; text: string; full: boolean }
  export interface DreamSelection { notes: DreamNote[]; excludedFlagged: number; sourceChars: number }
  export function selectDreamNotes(rows: DistilledRow[], projectSlug: string, opts: {
  ```

### Task 3: Validate, label and cap

**Files:**
- Create: `src/dream/validate.ts`
- Test: `src/dream/validate.test.ts`

**Interfaces:**
- Consumes: `RawDream`, `RawEntry` (Task 2); `DreamNote` (Task 1).
- Produces:
  ```ts
  export interface DreamEntry extends RawEntry { confirmed: boolean; ref: string; alsoRefs: string[]; surfaced: number }
  export interface DreamPage { overview: string; sections: { heading: string; entries: DreamEntry[] }[]; conflicts: { a: string; b: string; about: string }[]; gaps: string[] }
  export interface DreamStats { kept: number; dropped: number; cut: number; cited: number; coverage: number; confirmed: number; ratio: number }
  export const MAX_ENTRIES = 40; export const MAX_BODY_BYTES = 12_000; export const MAX_RATIO = 0.35;
  export function validateDream(raw: RawDream, notes: DreamNote[], sourceChars: number, measure: (page: DreamPage) => number): { page: DreamPage; stats: DreamStats }
  ```
  - `measure` returns the rendered body's byte length; Task 4's `renderBody` is passed in, so validate stays free of render.
  - `coverage` is cited notes / input notes. `ratio` is body bytes / `sourceChars`.

- [ ] **Step 1: Write the failing tests:**

  - `"drops sources out of range, and also-refs out of range"`: source 0 and source N+1 are dropped; `also: [99]` becomes `[]`.
  - `"labels from status"`: one entry per status, expecting confirmed `[true, true, false, false]` for `verified`, `transcript-supported`, `unbacked`, `unchecked`.
  - `"drops conflicts that point at unknown notes"`.
  - `"cuts unconfirmed least-retrieved entries first until within caps"`: 45 entries → 40 kept, all confirmed ones kept, `cut === 5`. Also a `measure` stub exceeding `MAX_BODY_BYTES` cuts further.
  - `"computes coverage and ratio"`.
- [ ] **Step 2: Run** `npx vitest run src/dream/validate.test.ts`. Expected: FAIL.
- [ ] **Step 3: Implement** `validateDream`.
  - Normalise text with `s.replace(/\s+/g, " ").trim()`.
  - Cut in order of (confirmed asc, surfaced asc, original position desc) until count ≤ 40, `measure ≤ 12000` and the ratio is ≤ 0.35 (when `sourceChars > 0`).
  - Remove sections left with no entries.
