# vir Marketing Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the twelve-block single-page marketing site from the spec as a static Astro build in `site/`, deployable to Vercel.

**Architecture:** Astro renders every block to static HTML; two React islands (`Loop`, `NoteTabs`) hydrate `client:visible`. All numbers and URLs come from `site/src/consts.ts`; build-time stats (npm downloads, GitHub stars) come from a fetch helper that degrades to `null` instead of failing the build. Pure logic (stats fallback, note highlighter) is unit-tested with vitest; blocks are verified by building and inspecting the output.

**Tech Stack:** Astro 7.3, React 19.2, Tailwind 4.3 (`@tailwindcss/vite`, CSS `@theme` — no `tailwind.config.ts`), `@fontsource` self-hosted fonts, vitest. Node ≥ 22.12 (Astro 7 floor); locally `/opt/homebrew/bin/node` v23 — nvm's default v20 will not run it.

**Spec:** `docs/superpowers/specs/2026-09-02-website-design.md`

## Global Constraints

- Only chromatic color on the page: `--accent: #7C6AF7`. ✕ columns use `--ink-muted`, never red.
- Tokens exactly as spec §6: `--paper #FAF9F7`, `--paper-2 #F2F0EC`, `--ink #141317`, `--ink-muted #5C5A63`, `--rule #E3E0DA`, `--accent-wash` = accent at 8%, `--code-bg #16161F`.
- Fonts: Instrument Serif (display), Inter (body, 17px, ≤62ch), JetBrains Mono (code/eyebrows). Self-hosted, no Google Fonts request.
- Total client JS < 20KB gzipped. `Loop` < 6KB, `NoteTabs` < 8KB.
- Every block readable with JS disabled. Islands render static HTML from their wrapper first.
- Motion only: scroll-reveal (opacity + 8px, 400ms, once) and the loop; both off under `prefers-reduced-motion: reduce`.
- Body copy ≤ 2,600 words; ≤ 6 screens at 1440×900.
- Copy is verbatim from spec §5 blocks 1–12. Do not paraphrase.
- Numbers in §11 of the spec (vault composition, sessions, tests, cost) ship measured or the block is cut. Until measured they live in `consts.ts` marked `MEASURE` and the build prints a warning listing them.
- Named exports, TypeScript strict, no `any`.
